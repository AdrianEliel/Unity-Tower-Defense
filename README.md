# Unity Tower Defense

A tower defense game I made in Unity using C#!

I started this project a few years ago as a way to learn more about Unity and game development. The main idea was to make a simple tower defense game where the player could place towers, defend against enemies, and progress through waves.

This project is no longer being worked on, but I'm keeping it here as a record of one of my earlier Unity projects.

## Gameplay

The game is based around keeping enemies away for the end of a path by using different defensive units

The player can:

* Place towers around the map
* Have towers automatically target enemies
* Attack enemies using projectiles
* Earn and spend money
* Upgrade towers
* Survive multiple enemy waves

## Project

The Unity project is located in the `Personal_Project` folder.

Some of the main parts of the project include:

* Enemy movement and health
* Tower placement
* Tower targeting
* Projectiles
* Enemy waves
* Money and upgrades

## What I Learned

This was one of my earlier projects with Unity, so a lot of the development was about learning how everything worked.

Some of the things I worked with were:

* C# scripting
* Unity GameObjects and Components
* Prefabs
* Basic enemy AI
* Collision and detection
* UI
* Managing different game systems
* Using Git for version control

Looking back at the project, there are definitely things I would do differently now, but it was a good project for learning the basics of building a game from scratch.
